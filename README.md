# Language-Identification-With-Multilingual-Machine
Developed a Machine Learning and Natural Language Processing (NLP) based multilingual system during my internship under the Python With Machine Learning course at Skill Development Institute.

The project performs:
• Language Identification
• English to Korean Translation
• English to Portuguese Translation
• English to French Translation
• English to Urdu Translation

Technologies Used:
• Python
• Pandas
• NumPy
• Scikit-learn
• CountVectorizer
• Multinomial Naive Bayes

The project uses custom multilingual datasets and machine learning models for language detection and translation tasks.
