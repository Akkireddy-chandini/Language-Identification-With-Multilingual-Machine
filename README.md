# 🌍 Language Identification With Multilingual Machine Learning

## 📌 Project Description

Language Identification With Multilingual Machine Learning is a Natural Language Processing (NLP) based project developed using Python and Machine Learning techniques.

The system is capable of:

* Detecting the language of a given text
* Translating English sentences into multiple languages

This project was developed during my internship in the 3rd year of my degree under the course **Python With Machine Learning** conducted by the **Skill Development Institute**.

✅ Language Detection

# 📊 Dataset Information

The project uses custom multilingual datasets stored in CSV format.

| File Name   | Purpose                 |
| ----------- | ----------------------- |
| dataset.csv | Language Identification |
| EK.csv      | English → Korean        |
| EP.csv      | English → Portuguese    |
| EF.csv      | English → French        |
| EU.csv      | English → Urdu          |

---

# ⚙️ Machine Learning Workflow

1. Dataset Loading using Pandas
2. Text Vectorization using CountVectorizer
3. Label Encoding using LabelEncoder
4. Dataset Splitting using train_test_split
5. Model Training using Multinomial Naive Bayes
6. Prediction and Translation Output
